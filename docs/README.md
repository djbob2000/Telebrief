# Документация Telebrief

Папка `docs/` содержит архитектурную документацию (собирается в один `index.html`) и рабочие документы проекта.

| Путь | Что там |
| --- | --- |
| `index.html` | **Архитектурная документация**: уровни L1–L3, эксплуатация, ADR. Собирается из `architecture/` |
| `architecture/` | Источник архитектурной документации: разделы в `.md` |
| `operations/` | Инструкции для оператора: прод, переезд сервера, бюджет OCI, резервные копии базы |
| `adr/` | Ранний ADR о расширяемости; актуальный реестр решений — в архитектурной документации |
| `editorial/`, `agents/`, `city_profiles/` | Редакционные заметки, правила для агентов, описания источников изданий |

## Архитектурная документация

### Запуск

```sh
cd docs
npm install          # один раз
npm run serve        # собрать index.html и открыть http://localhost:8766/
node serve.js 9000   # только сервер, другой порт
COMMENTS_FILE=/путь/comments.json node serve.js   # другой файл комментариев
```

### Как редактировать

`index.html` **генерируется** — правки вносятся в `architecture/`, затем `npm run build`.

| Команда         | Что делает                                                    |
| --------------- | ------------------------------------------------------------- |
| `npm run build` | собирает `index.html` из `architecture/` и проверяет ссылки   |
| `npm run check` | только проверка: внутренние якоря `#…` и пустые диаграммы     |

Структура `architecture/`:

- `l1/`, `l2/`, `l3/`, `ops/`, `adr/` — один раздел = один `.md`. Порядок в документе и меню — по префиксу имени: `03-components.md`.
- `_shell.html` — всё, что не разделы: шапка, боковая панель, слайд-шоу, скрипты. Места вставки: `{{nav}}`, `{{sections}}`, `{{aliases}}`.
- `aliases.json` — старые якоря слитых разделов → новые.

Front matter раздела:

```yaml
---
id: "l2-digest"                         # id раздела (якорь), обязательно
level: "L2"                             # L1 | L2 | L3 | OPS | ADR, обязательно
eyebrow: "Уровень 2 · Сценарий 2"       # подпись над заголовком
nav: "Сценарий 2: Ежедневный дайджест"  # пункт меню; без nav раздела в меню нет
group: "Выпуск"                         # только L3: подзаголовок группы в меню
navSepBefore: true                      # необязательно: разделитель в меню перед пунктом
---
```

В тексте:

- обычный Markdown + таблицы GFM; где Markdown не хватает (SVG-схемы, карточки, сложные таблицы) — сырой HTML без пустых строк внутри;
- диаграммы — блок ` ```mermaid `;
- «Коротко» — блок `::: tldr` … `:::`;
- id заголовка — `### Заголовок {#l1-names}`.

Не меняйте без нужды текст разделов, к которым привязаны комментарии: комментарий ищет свой блок по первым 80 символам текста.

Шрифты и Mermaid загружаются с CDN, поэтому для диаграмм нужен интернет.

### Файлы движка

| Файл                                            | Что содержит                              |
| ----------------------------------------------- | ----------------------------------------- |
| `tools/build.mjs`, `tools/check.mjs`            | сборка и проверка                         |
| `assets/docs.js`, `assets/docs.css`, `serve.js` | движок страницы, комментарии, сервер      |
| `comments.json`                                 | комментарии рецензентов (создаёт сервер)  |

Папка `docs/` исключена из образа Docker (`.dockerignore`).
