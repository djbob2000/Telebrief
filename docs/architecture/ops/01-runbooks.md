## Инструкции для оператора

Процедуры для оператора живут в `docs/operations/` в корне репозитория, рядом с конфигурацией, которую они меняют. Здесь — указатель и несколько правил, без которых легко навредить. Шаги процедур здесь не повторяются: они меняются вместе с сервером.

### Где что лежит

<div class="tw">

| Задача | Документ (путь от корня репозитория) |
| --- | --- |
| Деплой, доступ к серверу, состав сервисов, постоянное состояние, чек-лист релиза | `docs/operations/production.md` |
| Новый сервер, перенос конфигурации и базы, переключение | `docs/operations/server-migration.md` |
| Бюджет Oracle Cloud и ограничения Free Tier | `docs/operations/oracle-cloud-budget.md` |
| Резервная копия базы и восстановление | `docs/operations/database-backup.md`, `scripts/backup_to_mega.sh` |
| Миграции схемы | `scripts/migrate.py` (запускается сервисом `telebrief-migrate` перед стартом) |
| Превью дайджеста и статьи без доставки | `scripts/preview_digest.py`, `scripts/preview_article.py` |

</div>

### Правила, которые важно знать заранее

- **Push в ветку `dev` — это деплой.** Coolify собирает и перезапускает прод на каждый push. Перезапуск прерывает задачи, которые выполняются в этот момент; задачи, зависшие в `doing`, позже возвращает `retry_stalled_jobs`. Перед push проверьте, не идёт ли подготовка или генерация выпуска.
- **Превью тратит деньги.** `preview_digest.py` и `preview_article.py` вызывают те же модели, что и выпуск. Перед запуском на рабочей базе проверьте баланс OpenRouter.
- **Профили изданий не входят в образ.** `data/city_profiles/` монтируется с хоста; изменённый профиль попадает на сервер только шагом деплоя, который копирует каталог и сверяет его хеш внутри контейнера (`AGENTS.md` §3).
- **Воркеры запускаются только через `python -m src.worker`.** Голый `procrastinate worker` не устанавливает рантайм, и задачи падают.
- **Доставка со статусом `outcome_unknown` не повторяется сама.** Проверьте канал вручную и закройте запись в `publication_deliveries` сами ([Риски](#l3-risks)).

<div class="tw">
