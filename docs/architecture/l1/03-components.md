## Основные компоненты

Блоки со схемы выше — что делает каждый. Технологии, процессы и файлы в коде — на Уровне 3: [Репозиторий и стек](#l3-repositories). Соответствие названий в документе и в коде — в [глоссарии](#l1-names).

<div class="tw">

| Компонент | Что делает |
| --- | --- |
| **💬 Источники** | Городские Telegram-каналы и чаты, где жители и администраторы пишут о жизни города. Система читает их через обычный аккаунт Telegram, как читатель. Сборщик для групп Facebook есть, но выключен. |
| **🤖 Бот издания** | Чат владельца с системой: ручной запуск дайджеста или статьи, статус, справка. Через него же приходят уведомления о сорванном выпуске и о заканчивающемся балансе у провайдера моделей. Отвечает только владельцам из списка. |
| **📢 Telegram-канал** | Публичный канал издания. Сюда уходит дайджест одним постом и анонс статьи со ссылкой. |
| **📄 Telegra.ph** | Площадка для длинных статей: каждая статья публикуется отдельной страницей. |
| **⏱️ Управление выпусками** | Следит за расписанием: за полчаса до выпуска создаёт заявку и запускает сбор, проверяет, всё ли собрано и обработано, и в нужный момент передаёт заявку в редакцию. Ручная команда владельца создаёт такую же заявку. |
| **📥 Сбор** | Забирает новые и изменённые сообщения из источников. Каждая правка сохраняется отдельной версией, повторное чтение ничего не дублирует. |
| **🧠 Обработка знаний** | Делит сообщения на смысловые фрагменты, собирает похожие фрагменты в сюжеты, решает, касается ли сюжет города, и для важных сюжетов выписывает факты с точной ссылкой на исходные слова. Работает в фоне, независимо от выпусков; там же ведёт хронику сюжетных линий и память о долгих ситуациях и убирает отработавшие рабочие данные. |
| **📰 Редакция** | По замороженному снимку сюжетов отбирает материал, пишет дайджест или статью, проверяет каждое утверждение по исходным сообщениям и отдаёт текст на точечную правку. Нет проверенного текста — нет выпуска. |
| **📤 Доставка** | Превращает готовый выпуск в посты и страницы, отправляет их и при временной ошибке повторяет отправку. |
| **🗄️ База данных** | Единый источник правды: исходные сообщения и их версии, сюжеты, решения фильтра, снимки и выпуски. В ней же живёт очередь фоновых задач, поэтому задачи переживают перезапуск сервера. |
| **✨ Внешние сервисы ИИ** | Языковые модели (фильтр сюжетов, разбор, отбор, текст, правка), модель смысловых отпечатков (эмбеддингов) и модель для обложек статей. Языковые модели разрешены только из списка в настройках. |

</div>
