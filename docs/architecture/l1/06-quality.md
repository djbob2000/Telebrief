## Цели качества

Свойства, на которые ориентированы решения. Числа — текущие значения из кода или настроек, а не гарантии SLA.

<div class="tw">

| Цель | Что это значит сейчас | Где объяснено |
| --- | --- | --- |
| Верность источнику | Каждое утверждение выпуска опирается на исходное сообщение; выдуманные места, числа и причины блокируют публикацию. | [ADR-0003](#adr-0003) |
| Полнота | Каждый сюжет, отобранный в план дайджеста, обязан попасть в текст; несколько сюжетов могут стать одним пунктом. | [Сценарий 2](#l2-digest) |
| Быстрое чтение | Дайджест — один пост Telegram, сгруппированный по рубрикам. | [Сценарий 2](#l2-digest) |
| Местные новости без цензуры «по второму источнику» | Короткое сообщение жителя публикуется, если подано честно; вопрос не превращается в факт. | [ADR-0002](#adr-0002) |
| Своевременность | Дайджест — в 09:00, статья — в 21:15 по Киеву. Если воркер пропустил минуту выпуска, планировщик догоняет её в течение 2 часов. | [Сценарий 2](#l2-digest) |
| Экономия на моделях | Языковая модель вызывается для сюжетов, а не для каждого сообщения; фильтр разбирает сюжеты пачками. | [ADR-0001](#adr-0001) |
| Устойчивость | Очередь задач хранится в базе и переживает перезапуск; сорванный плановый дайджест система повторяет сама. | [Сценарий 2](#l2-digest) |

</div>
