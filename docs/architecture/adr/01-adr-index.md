# Реестр архитектурных решений (ADR)

Ключевые решения, которые объясняют, *почему* система устроена именно так. Формат — MADR: статус, дата, контекст, движущие факторы, рассмотренные варианты, решение, последствия, реализация. ADR не удаляют: устаревшее решение получает статус «Заменено».

<div class="tw">

| ADR | Решение | Статус | Дата |
| --- | --- | --- | --- |
| [0001](#adr-0001) | Сюжеты из смысловых кластеров вместо разбора каждого сообщения (Event-First) | Принято | 2026-08-29 |
| [0002](#adr-0002) | Сообщение жителя публикуется без второго источника | Принято | 2026-08-30 |
| [0003](#adr-0003) | Нет проверенного текста — нет выпуска (fail-closed) | Принято | 2026-08-30 (статья), 2026-09-20 (дайджест) |
| [0004](#adr-0004) | Фильтр сюжетов не задерживает выпуск | Принято | 2026-09-15 |
| [0005](#adr-0005) | Статья распределяет место между сюжетами, а не отсеивает их | Принято | 2026-08-30 |
| [0006](#adr-0006) | Один проход автора и ограниченный редактор вместо каскада моделей | Принято | 2026-09-05 |
| [0007](#adr-0007) | Итоги периода строятся на хронике сюжетных линий | Принято | 2026-11-05 |
| [0008](#adr-0008) | Знания хранятся бессрочно, рабочие векторы — пока нужны | Принято | 2026-11-05 |
| [0009](#adr-0009) | Материал, уже вышедший в прошлой статье, не цитируется повторно | Принято | 2026-11-12 |
