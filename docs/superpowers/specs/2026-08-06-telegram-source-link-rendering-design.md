# Telegram source-link rendering

## Goal

Ensure grouped digest items render source links as one compact clickable arrow instead of exposing Markdown syntax or duplicate raw Telegram URLs.

## Scope

The grouped digest formatter will normalize source markup generated by the AI before appending the canonical source link. It will preserve the visible label of Markdown links, remove their destination URL from the item text, remove duplicate raw Telegram URLs, and append exactly one `[↗](url)` link when a valid source URL exists.

Existing digest structure, section headings, non-source formatting, and Telegram sending mode remain unchanged.

## Examples

Input item:

```text
Бердянск снова остался без электричества — перебои происходят ежедневно. [t.me/Brd24discord/208708](https://t.me/Brd24discord/208708)
```

Output:

```text
• Бердянск снова остался без электричества — перебои происходят ежедневно. [↗](https://t.me/Brd24discord/208708)
```

## Verification
