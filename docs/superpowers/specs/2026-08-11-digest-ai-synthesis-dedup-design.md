# Спецификация: AI-дедупликация и синтез событий в дайджесте (Pass 2c)

## Проблема

При сборе новостей из нескольких Telegram-каналов и чатов одни и те же события (например, график отключения воды, остановка маяка, приговор бывшему служащему, списки бесхозяйного жилья) попадают в итоговый дайджест в виде нескольких почти одинаковых пунктов с разными формулировками.

Текущая эвристическая дедупликация в Python:
1. Не ловит дубли с разной лексикой (порог похожести 78%).
2. При совпадении оставляет один пункт длиннее, теряя уникальные детали из второго источника.
3. Пропускает сервисные заглушки (например, `📭 На данный момент существенных новостей нет.`).

## Цель

1. Объединять сообщения из разных каналов об одном и том же событии в **один исчерпывающий пункт (рерайт/синтез)**, сохраняя все ключевые детали (адреса, графики, цифры, статус, контекст).
2. Гарантировать **сохранность структуры, рубрик и ссылок на источники**: ссылки привязываются детерминированно в Python по ID исходных сообщений.
3. Полностью исключить попадание сервисных заглушек (`📭`) в итоговый дайджест.

---

## Архитектура решения

Пайплайн обработки расширяется этапом **Pass 2c (AI Synthesis / Deduplication)**:

```
[Pass 1: AI-суммаризация каналов] (per-channel)
     ↓
[Pass 2a: Локальный парсинг + Quality Gate] (фильтрация мусора, рекламы и 📭)
     ↓
[Pass 2b: AI-классификация по рубрикам] (ID-based, без изменения текстов)
     ↓
[Pass 2c: AI-синтез и склейка дублей внутри рубрик] (НОВЫЙ ШАГ)
     ↓
[DigestFormatter] (сборка Markdown / Telegram Rich Message со ссылками [↗])
```

## Детали реализации

### 1. Очистка от заглушек в Quality Gate (Pass 2a)
В `_QG_DROP_PATTERNS` в [src/grouper.py](file:///Users/air/develop/Telebrief/src/grouper.py) добавляются паттерны для отсечения пустых сервисных сообщений:
- `📭`
- `существенных новостей нет` / `no substantive updates` / `нет новостей`

### 2. Этап AI-синтеза дублей (Pass 2c)

После того как буллеты классифицированы по рубрикам (Pass 2b), `DigestGrouper` вызывает метод `_synthesize_grouped_points`:

- Если в группе 1 пункт — он остаётся без изменений (экономия токенов).
- Для групп с 2+ пунктами формируется компактный JSON-запрос к AI-провайдеру:
  ```json
  {
    "group_name": "Коммунальная обстановка",
    "items": [
      {
        "id": 0,
        "text": "⚡ Отключение света и воды: В результате ночных происшествий без электроснабжения и водоснабжения остались ключевые районы города..."
      },
      {
        "id": 1,
        "text": "🚰 Обострение блэкаута и график подачи воды. В отдельных районах Бердянска свет и вода отсутствуют около недели; ограничили подачу графиком с 17:00 до 21:00 и организовали подвоз по адресам в Военном городке, на ул. Горбенко, ул. Правды, ул. 12 Декабря и ул. Морозова."
      },
      {
        "id": 2,
        "text": "🚰 Введение графика подачи воды из-за блекаутов: В Бердянске установили график водоснабжения — с 17:00 до 21:00. В некоторых микрорайонах города электричество и вода отсутствуют уже неделю."
      }
    ]
  }
  ```

- **Контракт ответа AI**:
  ```json
  {
    "synthesized_items": [
      {
        "point": "⚡ Отключение света и воды: В результате ночных происшествий обесточены и остались без воды ключевые районы города (АКЗ, Азмол, Лиски, Центр, Слободка, 8 Марта). Утренняя попытка подачи напряжения была кратковременной, обесточивание сохраняется.",
        "source_ids": [0]
      },
      {
        "point": "🚰 График подачи и подвоз воды из-за недельного блэкаута: В Бердянске введен график водоснабжения с 17:00 до 21:00. Для районов с длительным отключением организован подвоз питьевой воды по адресам: Военный городок, ул. Горбенко, ул. Правды, ул. 12 Декабря и ул. Морозова.",
        "source_ids": [1, 2]
      }
    ]
  }
  ```

### 3. Восстановление метаданных и ссылок в Python
Python по массиву `source_ids`:
1. Находит исходные объекты `GroupedPoint` / `ExtractedBullet`.
2. Объединяет имена каналов-источников (`source = "Бердянск, Бердянск 24"`).
3. Привязывает наиболее прямую ссылку на сообщение `source_url`.
4. Формирует итоговый список `GroupedPoint` для рубрики.

### 4. Защита от сбоев (Fallback & Guardrails)
- Если AI возвращает ошибку, таймаут или невалидный JSON, метод логирует предупреждение и возвращает исходные несжатые пункты рубрики без потери данных.
- Если AI пропустил какой-то `id`, этот пункт автоматически добавляется в конец списка.
