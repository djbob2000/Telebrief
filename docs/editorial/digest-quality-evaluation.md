# Проверка редакционного качества дайджеста

План: `docs/superpowers/plans/2026-10-04-readable-city-digest.md`.
Снимки synthetic-v1 созданы до настройки нового writer/editor; live source prose в Git не сохраняется.

Development: rich_utilities, quiet_day, local_contrasts, practical_services.
Holdout: partial_announcements, community_microdetails. Не использовать holdout для настройки prompts.

Критерии: 100% выбранных Stories/facts; honest single-source attribution; неизменные цитаты; лимит Telegram; no fallback. Editorial score: пять измерений 0–4 (hierarchy, cohesion, repetition, usefulness, detail/attribution), сумма ×5. Оценки выставляются по готовому тексту с примерами; отсутствующие source details не дописываются.

Synthetic cases используют один общий тестовый блок, чтобы сравнивать синтез независимо от Selection/rubric assignment. Этот набор не заменяет реальные multi-rubric снимки и не подтверждает production rollout сам по себе.

Baseline и новые варианты выполняются через offline replay, без базы и доставки. Отчёты/тексты: `data/previews/digest-evaluation/` (ignored). Отказы учитываются вместе с успешными результатами.

Статус: сравнение завершено; rollout отклонён по редакционным и эксплуатационным критериям.

## Результаты 04.10.2026

Проверены готовые тексты, а не только validator PASS. Оценки — редакционная самооценка автора реализации; независимое слепое ревью не выполнялось. Субагенты не использовались по просьбе пользователя.

Synthetic scores: пять измерений 0–4, сумма ×5. Нельзя интерпретировать 100/100 короткого искусственного примера как идеальность реального продукта. На реальном выпуске каждый из шести текстов получил [3,2,2,3,4]: тематическая иерархия присутствует, но связность и повторы слабы; фактура сохранена, практическая польза ограничена доступными сведениями.

Примеры нерешённых дефектов: «в районе РТС ... нет электричества уже неделю» и следом «свет ... так и не дали» повторяют одну мысль; «Отдельное сообщение указывает» заменяет рассказ о городе рассказом об источнике; «АКЗ: сообщения ... расходятся» дублируется в теле. В synthetic holdout несколько пунктов одинаково начинались «По местному сообщению», а поздняя атрибуция «...; по местному сообщению» нарушала плавность фразы. Эти дефекты не объявлены фактическими блокерами.

Технически все принятые кандидаты имели 100% metadata Story/material-fact coverage и укладывались в один Telegram пост. Семантические binding checks частично `not_evaluated`: техническое принятие не доказывает полноту литературной или смысловой оценки. В одном раннем кандидате редактор придумал «в другом доме» без места в источниках; добавлен узкий safety regression check с контролем, который сохраняет такую формулировку, когда она явно есть в единственном источнике.

Снимок run 306 реконструирован из sealed publication inputs и source revisions в `REPEATABLE READ READ ONLY` транзакции. Это реконструкция, не доказательство точного совпадения со всем контекстом оригинального запуска. После экспорта replay не читает БД. Снимок содержит 18 Stories и четыре рубрики; SHA256 экспортированного JSON: `7f1c82366c4d84b9427d32ada6adad471c4118f3197fac1a2efa2f1cc89d18ca`. City profile на сервере и локально совпал: `8f98735cf79b6501b5f76e7c879f7611ae548ade825fec12396d0fcd0850a503`. Новые replays требуют hash географического профиля и прекращаются до provider call при его изменении. Версия модели разрешалась из имеющейся конфигурации и записывалась в каждом результате; provider availability не гарантируется снимком.

Synthetic holdout использован для итогового сравнения. После анализа его регрессий дальнейшие варианты не получают статус проверки на независимом holdout; для следующего допуска нужен новый заранее закрытый набор реальных окон. Промпт thematic-v3 исправлялся по реальному development run 306; его результаты не заменяют повторный holdout.

## Решение

`digest_writer_material_format=legacy` и `digest_editor_scope=targeted_items` остаются production defaults. Новый компактный материал и полный тематический scope доступны для дальнейших offline сравнений. Обязательная AI-редактура без замечаний доступна только экспериментальным CLI флагом. Подмена готового текста технической склейкой не добавлена, фактические проверки не ослаблены, подтверждение из двух источников не требуется.

Активация, деплой нового режима и просмотр первых трёх штатных выпусков не выполнены: acceptance criteria не достигнуты. Следующая работа — на новых реальных снимках отделить ограничения writer/editor от ограничений состава плана, проверить источник повторяющихся фактов и неясных контекстных пунктов до планового утверждения, а затем повторить сравнение. Удалять утверждённые факты из готового текста ради хорошего балла нельзя.
